## She Can Foundation — Contact Form Page
A responsive contact form webpage built for She Can Foundation, a government-registered NGO empowering women across India. Includes form validation, a topic dropdown, loading state on submit, and a success confirmation screen. Built with pure HTML, CSS, and JavaScript — no frameworks or libraries.
